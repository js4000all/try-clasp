# try-clasp

## CLASP の始め方

```bash
clasp login
```

`open`でデフォルトブラウザで開くか、`copy`して任意のブラウザで開く。
画面の案内に従って必要な権限を与える。
認証情報は`~/.clasprc.json`に保存される。

### 新しいプロジェクトを作る

```bash
clasp create <project-name>
```

### 既存のプロジェクトを clone

```bash
clasp clone <script-id>
```

### GAS 　の管理画面を開く

```bash
clasp open
```
